Privacy

Last updated 20 October 2026

This website

gappa.me is a personal portfolio. It uses PostHog (EU servers) in cookieless mode to count page views and which terminal commands are typed, including questions asked with ask. Nothing is stored in your browser, no account is created, and your browser's Do Not Track setting is respected.

Questions you send with ask go to a small server function that uses a language model to pick the matching project. The question is processed to answer it and is not used for anything else.

gog-cli (Google sign-in)

gog-cli is a private command-line tool that only Emilio Gappa uses on his own computer to read his own Gmail, for example to save attachments. It requests read-only access. Data it reads stays on that computer; it is not sent to any server operated for this tool, not shared with third parties, not sold, and not used for advertising or to train AI models. Access can be revoked at any time at myaccount.google.com/permissions.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
